## 1. Dependency Map（§1，改码前冻结）

```text
ProviderManager(eastmoney→tencent, get_all_a_shares→(total,quotes), get_index_quote, get_kline)
  ↓
IntradayMarketDataService.map_quote_snapshot / get_intraday_bars
  （V3Contract 快照：event_time/known_at/source/quality/stale/suspended；R5-01 时间语义）
  ↓                                   ↓
IntradayFastLaneService（唯一 Runtime Factory 构建，Worker/MCP/HTTP 同一实例能力）   ReadEntry/PositionDecisionContext
  = 全市场 Quote → Coverage Gate        （quote+bars+facts，R5-06 evidence 真聚合）
    → L1 Overlay（EOD Feature × Quote × EOD Levels × index_return[Index Quality Gate]）
    → Scanner（VOLUME_SURGE/STRONG_VS_INDEX/SHARP_DROP/BREAKOUT_20D/FAILED_BREAKOUT/
      NEAR_SUPPORT/NEAR_RESISTANCE；stale 绝不入选；index 不可信→relative=UNKNOWN）
    → Active Pool（Portfolio>Watchlist>EOD Raw>Intraday，现态过滤）
    → Deep（DeepMarketDataService periods[5m/15m/60m]，fetch 后 known_at，per-period provenance）
    → DataQualityAggregator（GOOD/DEGRADED/UNAVAILABLE 统一聚合，下游只透传）
  ↓                                   ↓
IntradayTriggerLoop（45s/90s/600s 三 lane）   ActivePlanResolver（Repository 层冻结）
  plan 来源 = ActivePlanResolver：         - Entry：真正最新 Decision 的 Plan
  - trigger 45s：price trigger/cancel        （最新无 Plan→NO_ACTIVE_ENTRY_PLAN，不回退）
  - fastlane 90s：FastLane（写 Attention）  - Position：TradeLedger.entry_plan_id 绑定 Plan
  - evidence 600s：EventPoll                （无绑定→NO_TRADE_PLAN_BINDING，不替换）
  → heartbeat 30s 节流落库                  - trigger/cancel/stop/target 任一即合法
    operational_health_events               - effective_from/max_wait_sessions 生命周期
  ↓
HTTP /api/v3 + MCP v3_tools（同一 Runtime Factory，engine=None 唯一副作用差异）
  ↓
ChatGPT（MCP 原样透传 status/coverage/data_quality/sources/deep，绝不重新包装 AVAILABLE）
```
