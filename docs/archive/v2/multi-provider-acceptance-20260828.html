多数据源与 K 线缓存上线验收（2026-08-28）¶

验收范围与口径¶

版本：7828f2a。服务器：/opt/gpt-market，容器：market-mcp。

改造前 Top30 于 10:36 左右、改造后 Top30 于 11:03 左右采集，均为同一交易日的实时结果，但不是同一秒的可回放历史快照。A 股盘中价格和预筛 shortlist 会变化，因此排名差异不能全部归因于 K 线恢复；本文只如实记录观察结果，不据此调整评分。

评分函数、权重、主板过滤、扫描参数和 Top30 排序规则均未修改。数据层额外修正了全市场分页按动态涨跌幅排序导致的重复证券：改为按代码稳定分页，并在 Provider 出口按代码去重。

自动化与协议验收¶

  • 本地单元/契约测试：44 passed, 5 skipped。
  • MCP：initialize、tools/list 和 get_quote(002284) 成功；8 个原工具完整保留。
  • GPT JSON：/gpt/{secret}/stock/002284 成功，实测由 Tencent 回退提供真实价格。
  • Live：唯一 nonce URL 连续 10 次均为 HTTP 200，端到端 1.0–2.0 ms；handler 内部日志约 0.2 ms。
  • 容器：healthy；SQLite 位于 /opt/gpt-market/data/kline_cache.sqlite3。
  • 首轮缓存后 SQLite：7,584 根 bar、96 个 series。
  • Provider 健康实测：Eastmoney 125/146 成功、21 失败；Tencent 30/30 成功。Eastmoney 断链时 Tencent 已实际接管。
  • 故障测试：单元测试覆盖 Eastmoney 失败转 Tencent、双源失败有缓存返回 stale/OLD、双源失败且无缓存抛出 ALL_PROVIDER_FAILED。

结论¶

数据层达成验收目标：首轮初始化后第二、三次扫描缓存命中超过 96%；K 线 90/90 可用；Eastmoney 失败时 Tencent 实际接管；Top30 不再出现重复代码；MCP、GPT JSON 和 Live 路由兼容，Live 响应不受后台网络刷新影响。评分与扫描规则没有修改。
