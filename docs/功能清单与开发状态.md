# gpt-market 功能清单与开发状态

> 最后更新：2026-08-29（Asia/Shanghai）
> 说明：本文件是功能级状态矩阵；日常任务进度见《工作状态》。状态必须有代码/测试依据，设计完成不等于功能实现。

## 1. 状态定义

| 状态 | 含义 |
|---|---|
| 已实现 | 当前代码存在且有相应测试/运行证据 |
| 部分实现 | 有基础能力，但未满足 V3 完整要求 |
| 仅设计 | Baseline/详细设计已完成，尚无实现 |
| 未开始 | 尚未开发 |
| BLOCKED | 缺少必要时点数据或外部条件，禁止伪完成 |
| V4 | 明确不属于 V3 |

## 8. 状态更新规则

功能开发每完成一个可验证步骤：

1. 更新本矩阵对应行；
2. 更新《工作状态》的完成、验证和下一步；
3. 运行文档 HTML 生成与同步检查；
4. 中文提交并立即推送；
5. 设计完成只标“仅设计”，直到代码、测试和必要真实验证通过才改“已实现”。
