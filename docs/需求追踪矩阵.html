gpt-market V3 需求追踪矩阵¶

基线：V3 Architecture Baseline 1.0

状态：实施前追踪基线

范围：覆盖《需求规格说明》全部 P0/P1；P2 在进入对应扩展阶段前再纳入阻塞验收。

1. 使用规则¶

  • 每个需求必须有 Phase、责任模块、数据落点、API/Job、测试、状态和证据承接；缺少任一项不得标记完成。
  • 待实现 表示设计已完成但尚无 V3 代码证据；部分已有 只表示 V1/V2 存在可复用能力，不等于 V3 验收通过；设计约束已确认 不等于功能实现。
  • 实施时在本表追加真实测试名、提交号、Migration、运行记录或验收报告，不用口头结论替换证据。
  • 状态变化必须与《功能清单与开发状态》和《工作状态》同步，并按开发规范及时提交、推送。

8. 完成判定¶

某行只有同时满足以下条件才可标记“已完成”：

  1. 对应 Migration/表或明确的无状态实现已经合并；
  2. API/Job 契约已实现并通过契约测试；
  3. 单元、集成及必要的 Replay/回归测试通过；
  4. 《功能清单与开发状态》《工作状态》已同步；
  5. 中文提交已推送，并在“当前证据”记录提交号、测试记录或验收报告。
